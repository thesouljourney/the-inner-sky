## 1. 这份「锁」不是一句宣告

三份写作指令都用 sha256 逐字钉在 `tests/run-tests.js` 里:

| 版本 | 指纹 |
| --- | --- |
| `compass-v1` | `df3b0a8385d86155` |
| `compass-v1.1` | `f81a63bee5bb64d2` |
| **`compass-v1.2`(已锁)** | **`a06710405bc99c8e`** |
| v1.2 的样本文案 | `afd185f8e09f4739` |

**任何一个字被改动,整批测试立刻红。** 实测过:把 v1.2 里的「慢一点没有关系」
改成「慢一点也没关系」——一个字 —— 立刻 7 项失败,而且会指出
「第 726 字起不同」,不必自己比对两千字的 prompt。

服务端 `docs/edge/compass-generate.ts` 里各版本的副本也一起钉住,
两边不一致就红,线上也会回 `prompt_mismatch` 400。

## 2. 要改写法的时候怎么做

**开新版本,不要就地编辑已锁的版本。**

```js
// assets/compass-generation.js
var SYSTEM_V13 = [ … ].join("\n");
var SYSTEMS = { "compass-v1": …, "compass-v1.1": …, "compass-v1.2": …, "compass-v1.3": SYSTEM_V13 };
var PROMPT_VERSIONS = [ …, "compass-v1.3" ];
var DEFAULT_PROMPT_VERSION = "compass-v1.3";   // 只有再次通过 voice review 才改这一行
var VOICE_BASELINE = { version: "compass-v1.3", … };
```

同一份也要加进 `compass-generate.ts` 的 `SYSTEMS`。
预览页的 PROMPT 切换会自动多出一个选项,可以直接 A/B。

**v1.2 永远保留。** 它是往后所有版本的对照基准 —— 少了它,
「新版是不是真的比较好」这个问题就没有答案。

## 3. v1.2 到底锁了什么

三件事,是 v1.1 通过人工审阅后仍然剩下的问题:

**① 方向那一句不要变成模板**
v1.1 四张卡全部以「所以…」收尾,连着读就是一份 AI 建议清单。
v1.2 规定四张里最多一张可以这样收尾,并给出替换句式;
方向也可以直接融进最后半句,不必自成一句建议。

**② 只能说证据授权你说的事**
机制成立 ≠ 可以推出一个关于现实的结论。不准替使用者判断:
某个人值不值得信任、某段关系安不安全、该不该继续、准备好了没有、
该留下还是离开、其实没有风险、只是想太多。
`reflectionPrompt` 同样不准把答案预设在问题里。

**③ Calls 不是 Moves**
calls 回答的是「就算没有人要求、就算没有实际用途,我还是会往哪里靠近」,
不是「怎样重新有动力」。自检:把标题换成「怎样让我重新有动力?」
内容还成立,就是写错了。

## 4. 现行基准的样子(C1 那一组机制)

| 方向 | coreInsight |
| --- | --- |
| 01 什么让我安定 | 你不是不想说,多半只是还没把自己整理好。 |
| 02 什么让我前进 | 你会投入很久的事,通常是你说得出为什么要做的那一种。 |
| 03 什么正在消耗我 | 真正让你累的,可能不是靠近,而是靠近之前那一次次的确认。 |
| 04 我正在被什么吸引 | 你容易被那些还有另一层可以理解的东西吸引。 |

完整四段文案在 `assets/compass-recorded.js` 的 `R12`。

## 5. 护栏怎么分工

**硬性拒收**(生成失败,不给通用文案):
占星词 / 玄学 / 心理诊断 / 贴标签 / 套话 / 编造原因 / 命令句 /
越权判断现实 / 问句预设结论 / 长度 / 非 JSON / 跨卡重复。
其中编造原因与越权两类**不准 retry** —— 让模型「重新解释一次」正是要避免的事。

**只量测不拒收**(交给人看):
分析腔、收尾词重复、moves × calls 重叠、四张卡的开头变化。
四张连着读像不像同一个模板,自动挡会挡错,所以只标记。
