# 我的内在指南 · 内容智能系统规格

> 这份文件只定义**内容系统**：它该说什么、不该说什么、凭什么说。
> 不含任何实作。生成引擎、Prompt、API 一律还没有写。
> 架构可行性与资料独立性的调查，见 `INNER-COMPASS-ARCHITECTURE-AUDIT.md`。

---

## 第一部分 · 这个东西是什么

### 它不是

- 又一份占星报告
- 第十个生命主题
- 生命脉络的摘要
- 星盘说明
- 性格描述
- 预测系统
- 灵性解读
- 励志语录产生器

### 它是

把**已经存在的、关于这个人的理解**，压缩成少数几句他能真的带回日常生活的观察。

产品的移动方向是：

```
认识自己   →   带着这些理解继续生活
```

生命蓝图 / 九个主题 / 生命脉络负责前半段。
内在指南负责后半段。

### 使用者读完应该有的反应

> 「这好像真的是我在做的事。」
> 「这件事我一直有感觉，但说不出来。」
> 「很简单，但说得很准。」

**不应该**是：

> 「我在读占星。」

---

## 第二部分 · 最硬的一条限制：占星必须留在后台

**占星可以决定洞察。占星永远不可以主导体验。**

使用者看到的内在指南内容里，**不得出现**：

星座、宫位号码、宫位名称、行星、相位、度数、逆行、命主星、
南北交点、庙旺陷弱、元素、三方四正、盘面格局、任何占星术语。

不得写：

- 「因为你的月亮……」
- 「你的第十宫显示……」
- 「你的土星落在……代表……」
- 「你的星盘显示……」
- 「根据你的本命盘……」
- 「因为这个相位……」

连「你的占星显示……」这种说法，正常情况下也不该出现。

> 占星是这套系统的**证据**，不是这套系统的**语言**。

## 第三部分 · 三层架构

### Layer 1 · 占星智能（后台）

可以动用完整的盘面结构。任务只有一个：**收集证据**。
这一层的产物永远不会直接给使用者看。

### Layer 2 · 人类翻译（后台）

把盘面翻译成这些概念：

情绪需求 · 调节方式 · 安全感来源 · 行为模式 · 应对机制 ·
内在冲突 · 动力来源 · 消耗来源 · 反覆出现的张力 ·
发展方向 · 真正投入的条件 · 关系倾向 · 恢复条件

### Layer 3 · 生活经验（前台）

使用者看到的。必须用**普通话**描述**认得出来的生活经验**。

### 转换链

```
盘面配置
  → 心理 / 行为机制
    → 实际生活里会发生的事
      → 普通人说话的句子
```

**绝对不是**：

```
盘面配置 → 写得比较美的占星解释
```

## 第四部分 · 四个方向各自的职责

四个方向必须**分工明确**，不可以变成同一件事的四种说法。

### 01 · 什么让我安定 / What grounds me

**核心问题**：当这个人乱了、散了、不确定、很累、跟自己断线的时候，
什么条件能真的让他回到比较稳的状态？

**关于**：情绪调节、安全感、恢复、消化、归属、内在稳定、
让这个人能沉下来的条件。

**不是**「你的月亮星座是什么」。
**不是**「什么让你开心」。

要指认的是**让他回到自己的那个机制**。

### 02 · 什么让我前进 / What moves me

**核心问题**：什么会真的启动这个人的动力、活力与「愿意动」？

**关于**：动机、主动性、活力、值得花力气的事、投入、创造、
移动、有在前进的感觉。

**不自动等于事业**。
**不是**「你应该成就什么」。

要指认的是**什么会让他重新愿意动起来**。

### 03 · 什么正在消耗我 / What drains me

**核心问题**：哪一个反覆出现的模式，最容易在他没察觉的时候把他的力气用掉？

**关于**：过度代偿、长期紧绷、回避、压抑、过度负责、
重复的内在冲突、压力模式、能量漏点。

- **不要**描述缺点
- **不要**让使用者觉得被指责
- **不要**下诊断

目标是**认出来**：

> 「我一直在这样做，但没意识到它有多耗。」

### 04 · 我正在被什么吸引 / What calls me

**核心问题**：这个人反覆被什么样的方向、经验或生活方式吸引？

**关于**：反覆出现的方向、好奇、意义、成长、探索、嚮往、
发展上的拉力、一再去寻找的经验。

**不是**「你的命定」「你的人生使命」「宇宙要你……」。

不做决定论式的断言。目的是指认**一股反覆出现的拉力**，不是预测未来。

## 第五部分 · 证据标准

> **单一落点永远不足以产生一条内在指南的主要陈述。**

每一条最终的洞察，至少要有：

**最低标准**

```
2 个互相独立的盘面讯号
```

**较好的标准**

```
2 个互相独立的盘面讯号
  +
1 个来自九个主题或生命脉络、独立生成的诠释模式
```

内部要把证据记成三类：

| 类别 | 意思 |
|---|---|
| **主要证据** PRIMARY | 直接对应这个方向的核心问题 |
| **支持证据** SUPPORTING | 解释这个模式是怎么运作的 |
| **交叉验证** CROSS-VALIDATION | 一份独立生成的既有诠释，指向同一个模式 |

**一个孤立的讯号不得成为最终洞察。**

⚠ 关于什么算「独立」，有一个重要的前提限制 ——
生命脉络是从九个主题生成的，两者**不能**同时算成两份独立证据。
详见架构审计 G 节，那里有完整的独立性分级。

---

## 第六部分 · 模式选择：压缩，不是罗列

内在指南**不该试图讲完所有事**。

每一个方向：

```
选 1 个主导模式
最多再加 1 个支持模式
没有第三个
```

复杂留在后台。简单留给使用者。

### 内部评分（概念阶段，本期不实作）

| 讯号 | 分 |
|---|---|
| 盘面上重复出现的独立证据 | +3 |
| 结构上的强相关 | +2 |
| 与这个方向直接相关 | +2 |
| 在九个主题里重复出现 | +2 |
| 在生命脉络里重复出现 | +3 |
| 有强力的反向证据 | −2 |
| 单一孤立落点 | −3 |
| 通用到谁都适用的诠释 | −3 |

分数**永远不给使用者看**。

## 第七部分 · 矛盾处理

**不要假设互相矛盾的讯号必须丢掉一个。**

人本来就可以同时装着两种需要。

例：

```
很需要独处   +   很需要说话
```

输出**不该**任选一边。要判断的是：**这个张力本身是不是就在描述这个人**。

可能的人类翻译：

> 「你可能不是一直想一个人待着，也不是一直需要有人陪。
> 很多时候，你需要先有自己的空间，把事情想清楚，
> 之后才比较想重新和别人连接。」

矛盾往往能产生**最被认出来**的洞察。

### 未来生成时的处理顺序

1. **侦测矛盾** —— 两个讯号指向相反的需求 / 行为方向
2. **判断两边是否都够强** —— 都达到证据标准才保留张力；只有一边强就照一般流程走
3. **保留有意义的张力** —— 不合并、不取平均、不各说一半
4. **把张力翻译成生活经验** —— 写成「在什么情况下会偏向哪一边」，不是写成「你很矛盾」
5. **不要把人写成不一致** —— 张力要写得像一个可理解的运作顺序，不是像一个缺陷

## 第八部分 · 多样性限制

四个方向**不可以变成同一个盘面模式的四次改写**。

### 失败的例子

```
什么让我安定：表达能让你调节
什么让我前进：表达能给你动力
什么正在消耗我：不表达会消耗你
我正在被什么吸引：你被表达吸引
```

就算「表达」在这张盘上真的极度重要，**这样也不可以**。

每一个方向应该呈现**同一个人的不同面向**。

### 多样性检查（四个方向都选完之后做）

问：**有没有两个以上的方向，本质上在讲同一件事？**

如果有：

1. 把这个模式**留在它最强的那个方向**
2. 另一个方向改用**次强的独立模式**

## 第九部分 · 写作声音

必须是：

简单 · 清楚 · 自然 · 温暖 · 具体 · 不评判 · 有情绪理解力 · 落地 · 好懂

**不可以**是：

文学的 · 诗意的 · 华丽的 · 戏剧性的 · 神秘的 · 过度灵性的 ·
像心理治疗的 · 临床的 · 学术的 · 占星的 · 励志的 · 像 AI 写的

目标**不是**：

> 「这写得真美。」

目标是：

> 「这就是我在做的事。」
> 「我一直不知道怎么说，但对，就是这样。」

---

## 第十部分 · 大白话原则

写的时候，想像是一个**很了解这个人的朋友**在跟他说话。

不是占星师、不是心理师、不是诗人、不是灵性导师、不是励志教练、不是 AI 助理。

| 用这种 | 不要这种 |
|---|---|
| 「你常常会先把事情处理好，才想到自己累不累。」 | 「你倾向于优先承担外部责任，而忽视自己的情绪需求。」 |
| 「事情还没确定的时候，你可能会一直放在心上。」 | 「你需要学习与不确定性共处。」 |
| 「有时候你不是想休息，你只是暂时不想回应任何人。」 | 「你需要通过独处恢复内在能量。」 |

---

## 第十一部分 · 不贴标签

避免反覆写「你是一个……」。**不要定义这个人的身份。**

避免：

- 「你是敏感的人。」
- 「你是缺乏安全感的人。」
- 「你是容易内耗的人。」
- 「你天生……」
- 「你注定……」

改用**情境语言**：

- 「当……的时候，你可能……」
- 「你很容易在……以后才发现……」
- 「有时候你会……」
- 「对你来说，真正困难的可能不是……而是……」
- 「你需要的可能不是……而是……」

> 描述模式。不要定义人。

---

## 第十二部分 · 有疗愈感，但不用治疗语言

内容可以让人觉得被安慰，但**不可以製造情绪强度**。

避免这类通用句：

「你值得被爱。」「你已经很努力了。」「宇宙会接住你。」
「相信自己。」「一切都会好起来。」「拥抱真实的自己。」「你的灵魂正在……」

疗愈感应该来自这个顺序：

```
认出   →   理解   →   允许   →   方向
```

範例：

| 阶段 | 句子 |
|---|---|
| 认出 | 「你常常会先把事情处理好，才想到自己累不累。」 |
| 理解 | 「忙的时候，你不太容易马上注意到自己的状态。」 |
| 允许 | 「休息不一定要等到事情全部结束以后才开始。」 |
| 方向 | 「最近有没有一件事，其实可以不用那么急？」 |

> 安慰来自**被準确地理解**，不是来自激励式的语言。

---

## 第十三部分 · 文学克制

**不要过度写作。**

避免：

「在世界的喧嚣里……」「灵魂深处……」「穿过漫长的黑夜……」
「命运的召唤……」「生命的河流……」「慢慢绽放……」
「找回遗失的自己……」「宇宙为你……」

改用**具体的人类经验**：

- 想太久
- 不想麻烦别人
- 明明累了还是继续
- 不确定的时候反复确认
- 有话想说但不知道怎么开口
- 一个人的时候比较容易想清楚
- 做没有意义的事情特别容易累
- 别人期待太多的时候开始想逃
- 做了决定以后还是会回头想
- 很忙的时候忘了自己其实已经累了

> **核心写作原则：不要写漂亮的句子。要写準确的句子。**

## 第十四部分 · 卡片输出结构

每一个方向最终产出三样东西：

### 1. 核心洞察 CORE INSIGHT

约 **15–35 个中文字**。

这句话要让使用者停一下。

### 2. 简短说明 SHORT EXPLANATION

约 **70–130 个中文字**。

说明这件事在日常生活里可能长什么样。
**不解释占星。不重複核心句。**

### 3. 一个温和的提问 GENTLE PROMPT

一句短的反思问题，直接扣住刚刚指认出来的那个模式。

### 完整範例

```
什么正在消耗我
WHAT DRAINS ME

核心：
你常常会先把事情处理好，才想到自己累不累。

说明：
忙的时候，你不太容易马上注意到自己的状态。通常是事情告一段落以后，
才发现自己已经撑了一阵子。对你来说，累有时候不是事情真的太多，
而是太久没有停下来看看自己还想不想继续。

提问：
最近有没有一件事，其实可以不用那么急？
```

## 第十五部分 · 通用性测试

每一条洞察在概念上都要通过这五关：

### TEST A · 随机使用者测试

把这句话给 100 个随机使用者看，大多数人会不会觉得「这说的是我」？

**会 → 太通用了，重写。**

### TEST B · 证据可追溯

这条洞察能不能追回到**至少两个互相独立的支持讯号**？

**不能 → 拒绝。**

### TEST C · 生活经验

这句话有没有描述一个认得出来的**行为、情境、内在反应或决定模式**？

**没有 → 重写。**

### TEST D · 去占星测试

把所有占星痕迹拿掉之后，一个完全不懂占星的人能不能**立刻**看懂整句话？

**不能 → 重写。**

### TEST E · 标签测试

这句话是在定义这个人「是」什么，而不是描述某件事「怎么发生」？

**是 → 重写。**

## 第十六部分 · 认出测试

问：**使用者能不能在这句话里，认出自己生活中真实的某一刻？**

| 差 | 好 |
|---|---|
| 「你需要相信自己的选择。」 | 「当别人已经很确定的时候，你可能会开始怀疑自己是不是想得太久。」 |
| 「你需要更多自由。」 | 「当每一天都已经被安排得很满，你可能会越来越没有动力，即使那些事情本身并不讨厌。」 |
| 「你很重视安全感。」 | 「事情没有说清楚的时候，你可能会比结果不好本身更难放下。」 |

> 要的是**认得出来的经验**，不是情绪张力。

---

## 第十七部分 · 想留给自己的几句话

**不可以变成另一个分析区块。**

它从**最强的那几个指南模式**衍生出来。

- 目标：**3 个**个人锚点
- 每则约 **30–70 个中文字**
- 可能的情境：当你开始怀疑自己的时候 / 当你觉得很累的时候 /
  当你面对选择的时候 / 当你感到迷失的时候

**不得引入全新的诠释。**
它们是已经被证据支持过的模式的**压缩提醒**。

写的时候问自己：**几个月后再读到，还有用吗？**

---

## 第十八部分 · 今天想问自己的一个问题

**不可以是随机励志问题产生器。**

问题必须从**这个人最强的指南模式**衍生。
同一个模式可以在不同时间长出不同的问题。

### 範例

模式：**过度负责**

题库可以是：

- 「最近有什么事情，其实可以不用你一个人负责？」
- 「有没有一件事，你继续做只是因为觉得自己应该？」
- 「如果今天不需要证明自己很可靠，你最想先放下什么？」

### 问题必须

- 简单
- 答得出来
- 不像功课
- 不假设创伤
- 不诊断
- 不逼人揭露
- 邀请反思，而不是要求反思

---

## 第十九部分 · 语言要求

产品是双语的。中英文要传达**同样的意思与同样的情绪重量**。

- **不做**逐字硬翻
- 中文要像中文写出来的
- 英文要像英文写出来的
- 两边都不可以比对方更诗意

### 中文特别注意

偏向**口语化的书面中文**。避免过多：

成语 · 比喻 · 抽象名词 · 文学句式 · 治疗术语 · 占星术语

阅读难度维持在一般成年使用者能轻鬆读懂的程度。

---

## 第二十部分 · 安全边界

内在指南**永远不可以**：

- 诊断精神健康状况
- 宣称创伤
- 推论受虐
- 宣称依附障碍
- 告诉使用者他有心理疾患
- 宣称确定知道潜意识动机
- 预测死亡、疾病或灾难
- 把占星当成客观心理事实来呈现
- 告诉使用者重大人生决定必须怎么做
- 製造对产品的依赖
- 暗示系统比使用者自己更了解他

适当时使用**校準过的语气**：

「可能」「有时候」「你或许会发现」「对你来说，比较容易出现的是」

但**不要过度**使用到让句子变得软弱或重複。

---

## 第二十一部分 · 最终内容哲学

这份规格里最重要的一句话：

> **不要告诉使用者「你的星盘是什么意思」。**
> **让使用者认出：「原来我一直是这样生活的。」**

英文：

> **Don't tell the user what their chart means.**
> **Help them recognize how they live it.**

我们要的最终反应是：

> 「这就是我。」

**不是**：

> 「这个占星解释很专业。」
> 「这句话写得真美。」
> 「这个 AI 很会安慰人。」

## 附录 · 最终检查表

写规格与未来写生成时，逐条确认：

- [ ] 使用者看到的内容里，零占星术语
- [ ] 完全不懂占星的人能看懂
- [ ] 每条洞察基于多个证据，不是单一落点
- [ ] 不是把生命脉络摘要一遍
- [ ] 四个方向职责不同
- [ ] 四个方向没有重複同一个模式
- [ ] 互相矛盾的需求可以并存
- [ ] 没有决定论式的人格标签
- [ ] 没有预测
- [ ] 没有心理诊断
- [ ] 没有通用励志语言
- [ ] 没有过度文学化的语言
- [ ] 没有神秘学语言
