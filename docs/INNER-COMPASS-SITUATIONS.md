## 1. 它在回答什么

前面的章节(个人星盘 → 九大主题 → 生命脉络)已经回答了「我是谁 / 我怎么运作」。
这一层回答的是后面那一句:

> **这些都知道以后,我可以怎么陪自己生活?**

```
ABOUT ME  →  FOR ME
「你通常……」 →  「这种时候，我可以回来看看这里。」
```

它**不是**第二个解读引擎:不读星盘、不呼叫任何 API、不产生新的主张。
输入只有**已经生成、已经通过验证**的四段文案(`coreInsight` + `explanation`)。

「For Me」**不等于**「Advice For Me」。认出来本身就有用。

---

## 2. 四个方向各有各的工作

| 方向 | 内部功能 | 必要条件 | 不要求 |
|---|---|---|---|
| grounds | RETURN | 授权情境 ＋ 朝「回到自己」的许可 / 定位 | 动作 |
| moves | MOVE | 授权情境 ＋ 朝「恢复动力 / 投入」的定位 | 动作 |
| drains | NOTICE | 授权情境 ＋ 认出成本在哪里 | 许可、指引、因应方式、动作、宽慰 |
| calls | FOLLOW | 授权情境 ＋ 朝「什么持续吸引你」的认出 / 定位 | 动作 |

**消耗的不对称是刻意的。** 它的工作是「帮我早点认出来」,不是「给我一个解法」。
不可以为了让四个方向在情绪上对称,就给消耗补上宽慰 / 许可 / 因应方式 / 一小步。

RETURN / MOVE / NOTICE / FOLLOW 是**内部产品语意**,永远不可以出现在画面上。

## 3. 安全性靠四件事

| | |
|---|---|
| ① 概念授权 | 句子只有在它需要的概念**真的被这份文案讲过**时才出现 |
| ② 方向契约 | 还必须被批准用在**当前这个方向**上(`allowedDirection`) |
| ③ 输出有限 | 18 条 × 可枚举 → 测试把**全部 40 句**列出来逐条审、sha256 钉住 |
| ④ 词典静态稽核 | 测试对整本词典扫命令句 / 万用空话 / 编造成因 / 心理诊断 / 越权判定 |

### 方向契约是一条安全边界

文案里出现了某个概念的说法,**不等于**那句话适合挂在这个方向底下。

```
语言命中 + 方向不符  →  这一条不出,该方向退回中性入口
```

**绝对不可以**为了让它对得上而重新诠释文案。

## 5. 语气守则

- 「也不迟 / 没关系 / 不急」这类宽慰,**只有在原文自己给了那个许可**时才写
- 确定度**不可以高过来源**(`hedges` 栏位记录必须保住的保留字)
- 情境必须是**可观察的生活处境**,不得预设内在自我评判
- 不用 `reflectionPrompt` —— 那一句专属于第 04 段「今天想问自己的一个问题」

---

## 6. 与第 02 段的关系(Guard A)

第 02 段「想留给自己的几句话」仍然只用 anchors-3.1。渲染前套一道:

```
锚点 × 目前画面上所有情境的正文与一小步
literal bigram similarity >= 0.35  →  丢掉那一句锚点
```

**只丢,不补句、不改写、不另外编一句凑三句。** 剩一两句是可以接受的结果。

**已知限制:** Guard A 是**字面**工具。字面低于门槛、语意上仍然重复的情形抓不到
(例如 v1.2 文案里同方向的锚点与情境,相似度只有 0.10)。
这是刻意的取舍 —— **不为此另建语意比对引擎**。

## 7. 既有使用者

情境在**渲染时现算**,记忆键沿用既有的 `generatedAt|promptVersion`。

- **唯读**:不写回快取、不动 `directions` / `generatedAt` / `promptVersion`
- 不重新生成、不清快取、不需要 compass-v1.3、不发任何请求
- 回查不过就整份不用 —— 四个方向全部退回中性入口,宁可少说,也不给没根据的句子

## 8. 画面契约 —— 情境是加值，不是门槛

> **2026-09-16 产品裁定:个人情境【永远不可以】变成内容的门槛。**

第 01 段有三层:

| 层 | 内容 | 何时存在 |
|---|---|---|
| L1 | 使用者已经生成的 `coreInsight` / `explanation` / `reflectionPrompt` | **永远** |
| L2 | 个人情境 + 已审定的那几句(+ 可选的第二句) | 只有安全认得出来时 |
| L3 | 原本的 `explanation` | 收在「为什么这适合我？」后面 |

四个方向**永远都印得出一行个人化内容**:

```
认得出情境   眉标(01 · 安定) → 情境      → 点开:情境 / 那几句 / 可选第二句 / 为什么这适合我？(原本两段)
认不出情境   眉标(01 · 安定) → coreInsight → 点开:coreInsight / 为什么这适合我？(原本的 explanation)
```

两种状态的**结构完全一样**,使用者不应该分辨得出哪一个对上了词典。
认不出来的方向**不是**错误、不是次等状态、不是内容不足 —— 它一样是个人化内容。

**绝对不可以出现**:「看看这个方向」这类空的入口、「无法识别 / 内容不足 / 待生成 /
证据不足 / 覆盖率」这类技术字眼,或任何 schema 标签(`一小步` / `Micro-action` /
`试试看` / `练习` / `Recognition` / `Orientation` / `Permission` / `Cost Signal` /
`RETURN` / `MOVE` / `NOTICE` / `FOLLOW`)。

一小步没有固定标签:有就是正文后面自然的第二句,没有就什么都不出,**不留空位**。

### 第 01 段的构图

天体罗盘(`assets/life/compass.webp`,品牌自己那张素材)是第 01 段的视觉中心,
四个方向绕着它。四个容器是**半透明的象牙白 + 香槟色细边 + 几乎没有阴影 + 里面留白很多**,
每个带一枚香槟细线的小记号(山 / 太阳 / 云 / 星)。

> 目标**不是**「四张卡片围着一张图」,
> 是「一个天体罗盘,它的四个方向里刚好放着我的个人化内容」。

小记号**只是视觉身分**,不带任何语意,不可以被读成结论。

方向的名字走 `dpT(d.zh, d.en)`:**中文模式只印中文**。概念图上的中英并列
**不可以**搬进中文模式(§6.2-1)。

章节编号只有 `01` 与 `02`。02 不是每个人都有,所以 03–05 **不编号** ——
否则少了一段就会露出 `01 → 03` 的缺口,等于把「你少了一段」写在画面上。
